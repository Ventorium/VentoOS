使用 skill-creator 技能为当前项目创建以下几个skill

1. 图标创建 skill：作为通用基础能力。需要建立统一的UI设计标准，保障后续所有的应用的图标保持统一而舒服。png格式，3倍像素。svg如果能做到就用svg，但是svg的表达能力有限，所以也可以用png

2. 系统功能迭代 skill：架构师的全局设计能力，强调要以操作系统级别的架构设计能力来完成系统功能设计，实际工作时要严格遵循系统架构设计。迭代时要保证遵循系统已有的架构设计，避免重复设计和跑偏。除非系统现有的设计不优雅，不完善，需要重构部分架构，这也是可以的。可以使用子agent来具体实施

3. 系统功能bug修改 skill：架构师的全局设计能力，强调要以操作系统级别的架构设计能力来修复系统功能，实际工作时要严格遵循系统架构设计。迭代时要保证遵循系统已有的架构设计，避免重复设计和跑偏。除非系统现有的设计不优雅，不完善，需要重构部分架构，这也是可以的。可以使用子agent来具体实施

4. 应用创建 skill：如果是全新应用，则需要先使用“图标创建 skill”来先创建应用的图标，然后补充应用的名称、描述、版本等内容，这些内容可以从用户的描述中自动提取，必要时询问用户。最后根据用户的需求开发应用。要求要以架构师的应用设计能力来先设计应用，用户描述不清楚的地方需要以优秀的产品经理的角度来细化需求，然后再执行应用开发。开发过程中需要尽量使用系统已有的能力，不要啥都自己造，所以这个skill可以把一些已有的能力列出来，这样体验上才一致。可以使用子agent来具体实施

5. 应用bug修改 skill：要求要以架构师的应用设计能力来先了解评估应用，用户描述不清楚的地方需要以优秀的产品经理的角度来细化，然后再执行bug修改。开发过程中需要尽量使用系统已有的能力，不要啥都自己造，所以这个skill可以把一些已有的能力列出来，这样体验上才一致。可以使用子agent来具体实施

所有的skill中都要提到 修改完成后提交git 并push
