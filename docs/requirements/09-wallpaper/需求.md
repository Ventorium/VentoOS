# 壁纸
1. 调用bing每日壁纸接口，每日存储当天的，6张，默认区域是zh-CN，默认1920*1080的图。实现方法就是接口 https://www.bing.com/HPImageArchive.aspx?format=js&idx=0&n=6&mkt=zh-CN，将得到的结果里的images[n].url拼接前缀 https://www.bing.com 即可得到每日6张壁纸
2. 现有的壁纸保留，在现有的下面加个分组显示bing壁纸
3. 现在的窗口是用的透明背景色+backdrop-filter blur(48px) saturate(200%) 来实现的 这个可做到玻璃磨砂效果 但是多个窗口会渐渐叠加。改为每个窗口独立从壁纸生成玻璃模糊效果。参考 实现
```css
.window {
  background-image: var(--blur-wallpaper);
  background-size: 100vw 100vh;
  backdrop-filter: none; /* 关掉原来的 */
}
```
然后动态计算 
```js
function updateWindowBg(el, x, y) {
  el.style.backgroundPosition = `-${x}px -${y}px`;
}
```
计算时需要节流。或者直接和现在的窗口位置计算逻辑一起处理最好
