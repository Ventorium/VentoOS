## 关键实现说明

### 玻璃模糊实现原理

```
motion.div (overflow: hidden)
  ├── [图片壁纸时] 模糊背景层 (position: absolute, inset: -24px)
  │     background-image: url(wallpaper)
  │     background-size: 100vw 100vh
  │     background-position: (24 - windowX)px (24 - windowY)px
  │     filter: blur(24px) saturate(180%)
  ├── [图片壁纸时] 半透明着色层 (position: absolute, inset: 0)
  └── 窗口内容层 (position: relative, z-index: 2)
        ├── 标题栏
        └── 内容区
```

- `inset: -24px` 使背景 div 超出窗口边界 24px，避免 blur 边缘伪影被 `overflow: hidden` 裁切后出现硬边
- `background-position: ${24 - left}px ${24 - top}px` 确保背景图像定位与桌面壁纸位置完全对齐
- 窗口拖动时 `left/top` 实时更新，`backgroundPosition` 随之更新，无需额外节流（React 批量更新已足够）

### Bing 缓存机制

- 使用 `OnceLock<Arc<Mutex<Option<BingCache>>>>` 全局单实例
- 每次请求检查缓存日期是否为今天，否则重新拉取
- 网络超时设置为 10 秒，拉取失败返回 `502 Bad Gateway`
