## 依赖关系

- 需求 1、3 需要后端 API 支持（更新挂载点、测试连接）
- 需求 2 需要后端 SMB 逻辑改动
- 需求 5 需要搭建测试环境（Docker SMB/FTP）
- 需求 8 需要任务服务（已有 taskService）配合

---

## 实现顺序规划

### 阶段一：纯前端快速修复（需求 6b、7、9、10、11、12）
所有来自 Explorer 的 UI 交互修复，无需后端改动。

### 阶段二：中量前端工作（需求 4、6a、6c）
文件查看器媒体播放器改进，全局禁用右键，Explorer 菜单栏新建窗口。

### 阶段三：前后端联动（需求 1、3、8）
存储源编辑（需要后端更新 API）、测试连接（需要后端 ping API）、文件上传进度。

### 阶段四：复杂修改（需求 2）
SMB 支持无 share 名称浏览。

### 阶段五：测试（需求 5）
VFS 集成测试。
