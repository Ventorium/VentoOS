# VFS 系统完整实现 - 任务拆解

## 现状分析

### 已完成
- ✅ VFS类型定义 (VfsMount, VfsNode, VfsFileContent 等)
- ✅ VfsManager 基础框架 (mount CRUD)
- ✅ Local filesystem: list_dir, read_file, read_file_raw, move, copy
- ✅ API路由: 9个端点
- ✅ 安全: 路径穿越防护
- ✅ Explorer 前端: 列视图 + 预览面板 + 拖拽移动
- ✅ FilePicker 组件 (仅 local filesystem)
- ✅ 前端API客户端

### 缺失
- ❌ Local: mkdir, delete, write/upload, search
- ❌ SFTP/FTP/SMB/S3 协议适配器
- ❌ 跨挂载点复制/移动
- ❌ 挂载点持久化 (重启丢失)
- ❌ 文件查看器/编辑器
- ❌ 右键菜单
- ❌ 键盘快捷键 (Ctrl+A/C/X/V)
- ❌ 多选操作
- ❌ 跨窗口剪贴板
- ❌ VFS文件选择器 (FilePicker 只支持 local)
- ❌ Shell 中打开

## 任务拆分

### T1: 后端 VFS 基础操作补全
**优先级**: P0 (其他任务依赖)

**范围**: 补全 local 协议缺失的操作 + 添加缺失 API 端点 + 挂载持久化

**子任务**:
1. `mkdir` - 创建目录 (endpoint: POST `/api/vfs/mounts/{id}/mkdir`)
2. `delete` - 删除文件/目录 (endpoint: DELETE `/api/vfs/mounts/{id}/delete`)
3. `write` - 写入文件内容 (endpoint: POST `/api/vfs/mounts/{id}/write`)
4. `upload` - 上传文件 (endpoint: POST `/api/vfs/mounts/{id}/upload`, multipart)
5. `download` - 下载文件 (已有 `raw` 端点, 增加 Content-Disposition)
6. `search` - 搜索文件 (endpoint: GET `/api/vfs/mounts/{id}/search`)
7. `stat` - 获取节点元信息 (endpoint: GET `/api/vfs/mounts/{id}/stat`)
8. 挂载持久化到 SQLite (ventoos-persist)
9. 重构: 提取 VfsProvider trait, local 实现为 LocalProvider

**验收标准**:
- 所有新 API 端点可正常调用
- 挂载重启后不丢失
- cargo test 全通过

---

### T2: SFTP 协议适配器
**优先级**: P0

**范围**: 基于 russh 实现 SFTP 协议的 VfsProvider

**子任务**:
1. 实现 SftpProvider: connect (复用 SSH 连接)
2. list_dir - 列出远程目录
3. read_file / read_file_raw - 读取远程文件 (流式)
4. write_file - 写入远程文件
5. mkdir - 创建远程目录
6. delete - 删除远程文件/目录
7. move_file - 移动/重命名
8. copy_file - 复制文件 (服务端如不支持则 read+write)
9. stat - 获取元信息
10. 权限信息解析

**验收标准**:
- 通过 SFTP 浏览远程服务器目录
- 上传下载文件正常
- cargo test 全通过

### T3: FTP 协议适配器
**优先级**: P1

**范围**: 基于异步 FTP 客户端实现 VfsProvider

**方案**: 使用 suppaftp (async-native-tls) 或自行实现 FTP 协议核心

**子任务**:
1. 添加 FTP 客户端依赖或实现核心协议
2. 实现 FtpProvider: connect
3. list_dir, read_file, write_file, mkdir, delete, move, stat
4. 支持 FTPS (TLS)
5. 被动模式支持

**验收标准**:
- 通过 FTP 浏览远程服务器
- 上传下载文件正常
- cargo test 全通过

---

### T4: SMB 协议适配器
**优先级**: P1

**范围**: 实现 SMB 协议的 VfsProvider

**方案**: 自行实现 SMB2/3 协议核心 (避免重依赖) 或使用轻量级 crate

**子任务**:
1. SMB2/3 协议核心实现或集成
2. 实现 SmbProvider: connect (share 挂载)
3. list_dir, read_file, write_file, mkdir, delete, move, stat
4. 认证: NTLM / 用户名密码

**验收标准**:
- 浏览 SMB 共享目录
- 上传下载文件正常
- cargo test 全通过

---

### T5: S3 协议适配器
**优先级**: P1

**范围**: 实现 S3/MinIO 对象存储的 VfsProvider

**方案**: 基于 AWS S3 REST API 自行实现 (避免引入完整 AWS SDK)

**子任务**:
1. S3 REST API 核心实现 (签名 v4, ListObjectsV2, GetObject, PutObject, DeleteObject, CopyObject)
2. 实现 S3Provider: connect (验证凭据)
3. list_dir (ListObjectsV2 + 模拟目录层级)
4. read_file / read_file_raw (GetObject 流式)
5. write_file (PutObject)
6. mkdir (PutObject with trailing /)
7. delete (DeleteObject / DeleteObjects 批量)
8. copy (CopyObject same bucket)
9. 兼容 MinIO 等自定义 endpoint

**验收标准**:
- 连接 S3/MinIO 浏览 bucket
- 上传下载文件正常
- cargo test 全通过

---

### T6: 跨挂载点操作
**优先级**: P1 (依赖 T1-T5)

**范围**: 实现不同协议挂载点之间的文件复制和移动

**子任务**:
1. VfsManager 中添加 `cross_mount_copy` 和 `cross_mount_move`
2. 流式复制 (读源 -> 写目标, 避免全量加载到内存)
3. 目录递归复制
4. 冲突处理策略 (覆盖/跳过/重命名)
5. 集成任务系统 (长传输任务化)
6. 进度反馈 (通过 WebSocket 实时进度)
7. 添加 API 端点: POST `/api/vfs/cross-copy`, POST `/api/vfs/cross-move`

**验收标准**:
- 从 local 拖动到 SFTP 目录可复制
- 大文件传输不阻塞 UI
- 进度可查看

### T8: 文件查看器/编辑器
**优先级**: P1

**范围**: 实现内置文件查看和编辑器

**子任务**:
1. FileViewer 应用框架 (注册为独立窗口应用, 可从 Explorer 双击打开)

   - 支持: .js .ts .json .yaml .yml .toml .rs .go .py .sh .css .html .md .sql .env .xml .ini .conf .log .txt
   - 语法高亮
   - 保存文件 (调用 VFS write API)
3. 图片查看器:
   - 支持: .png .jpg .jpeg .gif .webp .svg .bmp .ico .avif
   - 缩放/平移
4. Markdown 预览:
   - 支持: .md .markdown
   - 渲染后预览 + 编辑切换
5. PDF 预览 (只读):
   - 支持: .pdf
   - 使用 iframe 或 pdf.js
6. 视频/音频播放器:
   - 支持: .mp4 .webm .ogg .mp3 .wav .flac
   - 使用 HTML5 <video>/<audio>

**验收标准**:
- 双击常见类型文件可打开对应查看器
- 文本文件可编辑保存
