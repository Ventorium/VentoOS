作为系统底层的文件系统，到现在还没有完成，你作为项目架构师来阅读下需求@docs/requirements/01-core/ventoos-vfs.md

另外还有些补充：

1. 需要实现多个文件查看/编辑器，对于不同类型的文件实现查看和编辑。验收标准就是常见的文件类型可以双击打开，web端不好实现编辑的可以只做预览，比如pdf。然后性能是第一要素
2. 可以打开多个explorer窗口，可以实现不同的目录间复制文件。验收标准：从本地拖动到sftp目录里可以复制文件
3. 前端页面支持常见的快捷键操作。验收标准：cmd/ctrl+a可全选，cmd/ctrl+c可复制文件/目录，cmd/ctrl+x可以剪贴文件/目录，cmd/ctrl+v可粘贴文件/目录
4. explorer支持右键常见操作。验收标准：和windows/macos类似的右键体验，添加在shell中打开的右键菜单，点击后直接新开一个shell(基于xterm.js)并将文件路径复制上去
5. os ui级别要提供vfs文件选择器组件，后续k8s/redis等都可以通过vfs来选择文件/目录 路径。验收标准：在k8s选择kubeconfig路径时弹框可以选择vfs系统上的任意协议的文件

然后将大任务拆解下，用一个team或多个子agent去分别实现不同的协议，需求里的那些能力必须得实现
