# 自治测试巡检 - 任务拆解

> 创建日期：2026-04-23

## 三行摘要

- 功能定位：建立可复用的自治测试巡检能力，并立即执行首轮巡检
- 影响层级：Skill 规范、前端 Shell/App、Rust Core、前后端契约、测试体系
- 接口设计：主 agent 统一收口，子 agent 分层排查，问题与进度同步落文档

## 原始需求与拆解表

| 序号 | 原始需求 | 子任务 | 验收标准 | 状态 |
|---|---|---|---|---|
| 1 | 先建立自治巡检能力 | 创建 `ventoos-autonomous-test-sweep` skill | Skill 文件落库，可指导后续巡检 | 已完成 |
| 2 | 再做首轮自治巡检 | 运行基线命令并组织分层排查 | 形成首轮问题清单与优先级 | 已完成 |
| 3 | 中间过程和进度落文档 | 建立任务拆解、完成情况、验收报告三份文档并持续回填 | 文档位于本目录，包含表格与验证结果 | 已完成 |
| 4 | 可考虑子 agent 协作 | 设计并执行多 agent 巡检分工 | 至少一轮分层巡检使用子 agent 输出结构化结论 | 已完成 |
| 5 | 主动发现并解决问题 | 选择高优先级问题修复并做验证 | 至少完成首批高优先级问题修复或明确阻塞原因 | 已完成 |

## 本轮执行边界

- 先建立 skill，再按 skill 执行首轮巡检
- 首轮优先范围：Shell/Kernel、Kubernetes、Settings、Rust Core 契约与持久化
- 本轮默认不做大规模重构，只处理可在单轮内闭环的问题
