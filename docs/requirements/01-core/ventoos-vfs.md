# VentoOS - VFS / 资源管理设计

## 1. 模块定位

VFS 是 VentoOS 的系统级基础设施，不只是“文件管理器后端”。它的目标是把本地、远程、对象存储、K8s 文件系统乃至各类网盘统一为一套虚拟文件系统能力，再由资源管理器、导入导出任务、AI、数据库导出、Redis 导出等上层能力统一复用。

## 2. VFS 的核心目标

* 屏蔽底层协议差异。
* 提供统一路径与节点模型。
* 支持统一的目录/文件操作。
* 支持跨挂载点复制、移动、同步与后台传输。
* 为上层应用提供稳定的资源读写接口。

## 3. 第一阶段支持的挂载类型

* `local://`
* `sftp://`
* `ftp://`
* `smb://`
* `s3://`
* `cloud://<provider>/`

后续预留：

* `k8s://`
* `zip://`
* `memory://`

说明：

* 虽然用户重点提到 SMB、SSH、FTP、S3 和网盘，但架构设计上必须从一开始就按可扩展挂载协议实现。

## 4. 核心抽象模型

### 4.1 Mount

挂载点定义至少包含：

* 挂载 ID
* 显示名称
* 协议类型
* 根路径
* 凭据引用
* 是否只读
* 健康状态
* 能力声明

### 4.2 Path

统一路径格式建议：

`scheme://mount-id/path/to/resource`

例如：

* `local://desktop/Users/foo/Documents/a.txt`
* `s3://prod-assets/bucket-a/path/image.png`
* `sftp://server-01/var/log/nginx/access.log`

### 4.3 Node

每个节点至少包含：

* 路径
* 名称
* 类型：file / directory / link / object
* 大小
* 修改时间
* 创建时间
* 权限信息
* 内容类型
* 校验值
* 扩展元数据

## 5. VFS 基础能力定义

### 5.1 目录能力

至少要有：

* 列出目录内容。
* 创建目录。
* 删除目录。
* 重命名目录。
* 移动目录。
* 获取目录元数据。
* 搜索目录下内容。

### 5.2 文件能力

至少要有：

* 创建文件。
* 删除文件。
* 重命名文件。
* 移动文件。
* 读取文件内容。
* 写入文件内容。
* 追加文件内容。
* 获取文件元数据。
* 下载文件。
* 上传文件。

### 5.3 通用能力

至少要有：

* 复制。
* 批量复制。
* 批量删除。
* 批量移动。
* 判断是否存在。
* 权限能力探测。
* 预览能力探测。
* 获取可用操作列表。

### 5.4 传输能力

必须支持：

* 跨挂载点复制。
* 跨挂载点移动。
* 断点续传能力预留。
* 任务化执行。
* 冲突处理策略，例如覆盖、跳过、重命名。

## 6. 协议差异抹平策略

VFS 需要通过 Adapter 层抹平以下差异：

* 路径语义差异。
* 目录与对象存储的层级差异。
* 权限模型差异。
* 重命名与移动是否原子支持的差异。
* 时间戳和大小精度差异。
* 列表和分页模型差异。

上层不应该关心某个挂载点到底是 SMB 还是 S3，只关心这个节点具备哪些能力。

因此每个 Adapter 必须声明：

* 是否支持随机读写。
* 是否支持目录。
* 是否支持原子移动。
* 是否支持权限变更。
* 是否支持流式上传下载。

## 7. 资源管理器应用能力

基于 VFS 的 Explorer App 至少支持：

* Finder 风格目录导航。
* 收藏夹。
* 最近访问。
* 列表 / 网格视图切换。
* 预览。
* 复制、粘贴、拖放。
* 新建文件夹。
* 重命名。
* 删除。
* 上传、下载。
* 跨挂载点复制与移动。
* 后台传输任务查看。

## 8. 与其它模块的关系

VFS 不只是 Explorer App 使用，还必须被以下场景复用：

* 数据库导出文件保存。
* Redis 导出文件保存。
* K8s 日志下载。
* AI 生成文件或报告输出。
* 导入文件选择器。

## 9. AI 联动

向 AI 暴露的能力至少包括：

* 挂载列表。
* 浏览目录。
* 读取文件。
* 写入文件。
* 复制文件。
* 搜索文件。

高风险操作如删除或覆盖必须确认。

## 10. 性能要求

* 大目录支持分页与懒加载。
* 大文件支持流式读取与写入。
* 远程挂载支持元数据缓存。
* 传输任务不能阻塞前端。

## 11. 安全要求

* 凭据由 Rust Core 管理。
* 挂载可设置只读。
* 跨挂载点复制需要明确错误处理与审计。
