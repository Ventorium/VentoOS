# CLAUDE.md Harness 化重构 - 任务拆解

## 任务背景

本任务目标是基于 Harness 思维重构项目根目录 `CLAUDE.md`，在尽量保留原有内容的前提下，将文档重组为可执行、可验收、可评估的 agent 约束文档，并把验收闭环落到需求同级目录。

| 序号 | 原始需求 | 子任务 | 验收标准 | 状态 |

| 1 | 按 Harness 思维重构 `CLAUDE.md` | 重组为 7 个固定章节：角色约定、任务理解规则、Coding 规范、工具使用规则、安全约束、输出标准、自检机制 | `CLAUDE.md` 顶层结构与顺序符合要求 | 已完成 |

| 3 | 更新需求文档路径 | 将需求文档入口从仅 `01-core` 扩展为当前 `docs/requirements/` 下多个目录 | `CLAUDE.md` 中显式列出主要需求目录 | 已完成 |
