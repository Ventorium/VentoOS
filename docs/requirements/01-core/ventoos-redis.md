# VentoOS - Redis 模块设计

## 1. 模块定位

Redis 应用负责承接缓存、消息、会话、排行榜等 Redis 场景的连接、浏览、编辑、分析与运维，目标体验接近 Tiny RDM，同时与 VentoOS 的连接中心、任务系统、K8s 联动和 AI 助手打通。

## 2. 第一阶段支持范围

* Redis Standalone
* Redis Sentinel
* Redis Cluster

## 3. 连接模型

### 3.1 连接配置

每个 Redis 连接至少包含：

* 名称
* 分组
* 标签
* 主机 / 端口
* 用户名
* 密码引用
* 数据库编号默认值
* TLS 配置
* SSH / HTTP 隧道配置
* 模式类型：Standalone / Sentinel / Cluster
* 连接测试状态

### 3.2 连接组织能力

必须支持：

* 分组
* 收藏
* 搜索
* 最近使用
* 测试连接
* 复制连接

### 3.3 K8s 生成临时连接

允许从以下 K8s 资源生成临时 Redis 连接：

* Service
* Pod
* StatefulSet
* Ingress 或外部域名信息

生成逻辑可参考：

* 端口 6379 / 26379
* 容器名、环境变量、标签、注解
* 常见 Redis Helm Chart 命名规则

## 4. 信息架构

推荐布局：

* 左侧：连接、数据库切换、收藏视图。
* 中间：Key 列表。
* 右侧：Value 编辑器、TTL、元数据、命令结果、监控信息。

## 5. 核心能力

### 5.1 数据库切换

* 支持选择 DB index。
* 显示当前 DB 的 Key 数量估算。
* Cluster 模式下根据槽位和节点适配展示。

### 5.2 Key 浏览

必须支持：

* 扫描 Key。
* 模式匹配过滤。
* 类型过滤。
* TTL 过滤。
* 惰性加载。
* 收藏 Key 前缀。
* 查看大 Key 风险。

### 5.3 Value 查看与编辑

必须支持以下类型：

* String
* Hash
* List
* Set
* ZSet
* Stream
* JSON（若后端模块存在）

要求：

* 区分只读和编辑模式。
* 支持格式化展示。
* 支持 TTL 查看与修改。
* 支持二进制或超长内容的安全展示。

### 5.4 命令执行

必须支持：

* 命令输入。
* 历史命令。
* 收藏命令。
* 执行结果格式化显示。
* 危险命令拦截或确认。

危险命令示例：

* `FLUSHDB`
* `FLUSHALL`
* `KEYS *` 在大数据量环境
* 批量删除命令

### 5.5 批量操作

至少支持：

* 批量删除 Key。
* 批量导出 Key。
* 批量修改 TTL。
* Key 复制 / 迁移到其它连接。

所有批量操作必须进入任务系统。

### 5.6 监控与诊断

至少支持：

* INFO 查看。
* 内存使用概览。
* Keyspace 概览。
* Slowlog 查看。
* 客户端连接查看。
* 命令统计基础信息。

### 5.7 发布订阅与 Stream

第一阶段建议支持：

* Pub/Sub 频道订阅查看。
* Stream 消息列表查看与搜索。
* 生产者 / 消费组基础信息查看。

## 6. 导入导出能力

至少支持：

* 导出单个 Key。
* 导出查询结果。
* 批量导出为 JSON / CSV。
* 导出到 VFS 挂载点。

## 7. K8s 联动

Redis 模块应能从 K8s 中直接打开，避免用户手动：

* `kubectl port-forward`
* 新建连接
* 填主机端口

系统负责：

* 识别 Redis 服务。
* 自动建立代理链路。
* 创建临时连接。
* 打开 Redis 应用并注入上下文。

## 8. AI 联动

向 AI 暴露至少以下能力：

* 测试连接。
* 扫描 Key。
* 查看与编辑 Value。
* 删除 Key。
* 导出 Key。
* 查看 Slowlog 和内存概览。

## 9. 性能要求

* Key 浏览只能使用 SCAN 或等价增量机制，不允许默认全量拉取。
* 大 Value 和大集合必须懒加载。
* 监控页刷新频率可配置。

## 10. 安全要求

* 密码不进入前端明文。
* 高风险命令需二次确认。
* 批量任务必须可取消、可审计。
