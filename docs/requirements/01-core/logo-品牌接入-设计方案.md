# VentoOS Logo 品牌接入 - 设计方案

> 需求来源：用户提供 `assets/Logo.png`，要求接入前端项目，并根据不同使用位置做不同缩放；同时替换 favicon，并按当前 logo 风格优化锁屏页视觉，使其具备液态流动感。

## 设计目标

1. 将用户提供的品牌 Logo 统一接入 VentoOS 前端壳层。
2. 保持不同场景下的品牌一致性，同时按场景控制尺寸、密度和视觉权重。
3. 将锁屏页从通用登录卡片升级为更具系统感的品牌入口界面。

## 设计决策

### 1. 品牌资源统一接入

引入统一品牌资源入口，供以下位置复用：

* 顶部系统栏左上角菜单按钮
* 锁屏页主视觉
* “关于 VentoOS” 弹窗
* 浏览器 favicon

### 2. 尺寸与缩放策略

| 场景 | 策略 | 目标尺寸 |
|---|---|---|
| 顶部系统栏 | 小尺寸、保持清晰轮廓 | `18px` |
| 关于弹窗 | 中尺寸、作为品牌主标识 | `72px` |
| 锁屏页 | 大尺寸、作为主视觉中心 | `160px` 基准，响应式缩放 |
| favicon | 导出位图资源，避免手工描摹误差 | `32x32`、`192x192` |

### 3. 锁屏页视觉方向

采用已确认的 `A. 深海流带` 方向：

* 暗色深海背景
* 多层液态流带和柔和蓝色辉光
* 大尺寸 Logo 置于视觉中心
* 解锁面板降低重量，作为下半区浮层出现

## 实现边界

* 不改动窗口系统、路由和应用注册体系。
* 不扩展到 Dock 和应用图标体系。
* 不引入新的视觉依赖库，沿用现有 React、Framer Motion 与全局样式体系。

## 验证方式

* 新增前端测试，验证品牌 Logo 在锁屏页与顶部栏可渲染。
* 执行 `cd web && pnpm test`
* 执行 `cd web && pnpm build`
