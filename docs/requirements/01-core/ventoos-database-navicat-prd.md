# VentoOS 数据库应用 — Navicat UI 1:1 还原产品需求文档 (PRD)

> 版本：v1.0  
> 目标：以 Navicat Premium 为 UI 基准，1:1 还原页面布局、交互路径、信息架构与组件结构，原生支持 PostgreSQL / MySQL / SQLite 三种数据库，以及 SSL 与 SSH 隧道接入。视觉样式严格遵循 VentoOS 系统统一主题，不单独定义 Database 专属配色。  
> 排除范围：BI 工作区、Ent 付费功能（数据生成、逆向到模型、通过配置文件打开表、数据字典）、自动运行、模型（ER 图）。  
> 第一期数据库支持范围：**MySQL / PostgreSQL / SQLite**，不支持 SQL Server、Oracle、MariaDB、MongoDB、Redis 等其他类型。

---

## 1. 产品定位与核心目标

### 1.1 定位
VentoOS 内置的数据库专业管理应用，面向开发者与 DBA，参考 Navicat Premium 的桌面级交互深度进行 1:1 还原。不是简单的 SQL 执行器，而是支持连接管理、对象浏览、数据编辑、结构设计、查询编辑的完整数据库工作台。

### 1.2 核心目标
- **结构还原度**：布局结构、组件层级、交互路径、信息架构与 Navicat 1:1 还原；视觉样式遵循 VentoOS 系统主题。
- **连接能力**：支持 PostgreSQL / MySQL / SQLite；支持直连、SSL 加密、SSH 隧道。
- **对象管理**：浏览并 CRUD 管理表、视图、实体化视图、函数、查询等数据库对象。
- **数据编辑**：网格式表数据编辑，支持筛选、排序、分页、内联 CRUD。
- **结构设计**：可视化表设计器（字段、索引、外键、唯一键、检查、触发器等）。
- **SQL 查询**：多 Tab SQL 编辑器，可执行查询并展示结果集。

## 2. 设计规范（遵循 VentoOS 系统主题）

### 2.1 主题说明
数据库应用不定义独立配色，全部使用 VentoOS 系统 CSS Variables：
- 背景色：`var(--app-bg)`、`var(--surface-bg)`、`var(--panel-bg)`
- 文字色：`var(--text-primary)`、`var(--text-secondary)`、`var(--text-muted)`
- 边框：`var(--border-color)`
- 主色/激活色：`var(--primary-color)`
- 状态色：系统统一状态色（成功/警告/错误/进行中）

**禁止写死任何十六进制色值。**

### 2.2 间距与尺寸

| 区域 | 尺寸 |
|------|------|
| 左侧 Sidebar 默认宽度 | `240px`，最小 `160px`，可拖拽调整 |
| 右侧 Info Panel 默认宽度 | `200px`，可折叠 |
| 顶部 Toolbar 高度 | `44px` |
| Tab Bar 高度 | `32px` |
| 表格行高 | `28px` |
| 对象列表行高 | `26px` |
| 连接树节点内边距 | 左缩进 `16px/level`，上下 `3px` |
| 表设计器行高 | `28px` |
| 新建连接弹窗宽度 | `860px`（左右分栏）|
| 连接配置弹窗宽度 | `560px` |

## 3. 全局布局架构

### 3.1 主窗口布局

```
┌─────────────────────────────────────────────────────────────────────────┐
│  [Toolbar]  连接/新建查询/对象工具按钮（随选中对象类型变化）               │  h=44px
├──────────────────────────────────────────────────────────────────────────┤
│  [Tab Bar]  对象(固定首位) | 查询Tab1 | 查询Tab2 | ...                   │  h=32px
├────────────┬──────────────────────────────────────────┬─────────────────┤
│            │  [Content Toolbar]                        │                 │
│  Left      │  新建/编辑/删除/刷新/视图切换/搜索         │  Info Panel     │
│  Sidebar   ├──────────────────────────────────────────┤                 │
│  (连接树)  │                                            │  当前选中对象   │
│            │  [Main Content]                            │  的属性信息     │
│  w=240px   │  对象列表 / 表数据 / 查询编辑器            │                 │
│            │  / 表设计器                                │  w=200px        │
│            │                                            │                 │
└────────────┴──────────────────────────────────────────┴─────────────────┘
```

### 3.2 布局状态规则
- 左侧 Sidebar 可以通过拖拽边框调整宽度，不可完全折叠（最小 `160px`）。
- 右侧 Info Panel 可通过工具栏 "查看" 按钮切换显示/隐藏。
- 顶部 Toolbar 的按钮集合随当前数据库类型（PostgreSQL / MySQL / SQLite）和选中对象类型动态变化。
- Tab Bar 最左侧固定 "对象" Tab（对象浏览器），其余 Tab 为查询 Tab，可关闭。
- 多 Tab 并行：同一连接可打开多个查询 Tab，不同连接也可并行。

## 4. 连接管理

### 4.1 左侧连接树

**根节点：** "我的连接"（固定顶部，不可删除）

**树节点层级：**
```
我的连接
├── [分组文件夹]（黄色文件夹图标）
│   ├── [连接]（数据库类型图标 + 连接名）
│   │   ├── [数据库]（数据库图标 + 数据库名）
│   │   │   ├── [Schema]（若支持 Schema，如 PostgreSQL）
│   │   │   │   ├── 表
│   │   │   │   │   ├── [表名]
│   │   │   │   │   └── ...
│   │   │   │   ├── 视图
│   │   │   │   ├── 实体化视图（PostgreSQL 专有）
│   │   │   │   ├── 函数
│   │   │   │   └── 查询
│   │   │   └── ...
│   │   └── ...
```

**树节点样式：**
- 连接节点：左侧数据库类型图标（PostgreSQL 大象图标、MySQL 海豚图标、SQLite 图标）+ 连接名；右侧不显示额外信息。
- 连接状态用图标颜色或角标表示：已连接（绿点）、未连接（灰色）、连接失败（红点）。
- 分组节点：文件夹图标，可展开/折叠，支持嵌套。
- 当前激活节点：背景色高亮（`var(--primary-color)` 低透明度背景）。
- 展开/折叠箭头：节点左侧小三角，点击展开。

**树底部操作：**
- 底部搜索框（搜索节点名称）。
- 搜索框左侧：筛选按钮（按数据库类型筛选）、收藏筛选、标签筛选。

**树的右键菜单（连接节点）：**
- 打开连接 / 关闭连接
- 编辑连接
- 复制连接
- 删除连接
- 新建数据库
- 刷新

**树的右键菜单（数据库节点）：**
- 打开数据库
- 关闭数据库
- 新建 Schema（PostgreSQL）
- 刷新

触发方式：
1. 工具栏点击"连接"按钮。
2. 右键树空白区域 → 新建连接。

**弹窗：新建连接（选择类型）**

第一期仅支持 MySQL / PostgreSQL / SQLite 三种类型，弹窗简化为：

```

│                                          [🔍 搜索]       │

│  │  [图标]  │ │  [图标]  │                               │
│  │PostgreSQL│ │  MySQL   │                               │
│  └──────────┘ └──────────┘                               │
│                                                          │
│  全部                                                    │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐                 │
│  │  [图标]  │ │  [图标]  │ │  [图标]  │                 │
│  │  MySQL   │ │PostgreSQL│ │  SQLite  │                 │
│  └──────────┘ └──────────┘ └──────────┘                 │
└──────────────────────────────────────────────────────────┘
```

**布局细节：**
- 弹窗宽度 `520px`，高度自适应（内容较少，不需要 860px 宽的两栏布局）。
- 右上角搜索框，实时过滤图标（供未来扩展更多类型时使用）。
- 顶部 `最近使用过的`：大图标卡片（`72×72px` 图标 + 类型名），显示最近用过的类型（最多 3 个）。
- 下方 `全部`：中等图标卡片（`56×56px` 图标 + 类型名），固定展示 MySQL / PostgreSQL / SQLite。
- 点击图标进入对应类型的连接配置弹窗。

### 4.3 连接配置弹窗（以 PostgreSQL 为例）

**弹窗结构：**
- 标题栏：`[数据库图标] 新建连接 (PostgreSQL)`（编辑时：`[连接名]`）
- 顶部 Tab 栏：**常规 / 高级 / 数据库 / SSL / SSH / HTTP / 备注**
- 弹窗上方可视化连接示意图：`客户端图标 ——— 数据库图标`，下方分别标注 "VentoOS" 和 "数据库"（SSH 开启时中间加入跳板机图标）

**Tab：常规**
| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 连接名称 | 文本输入框（蓝色边框高亮） | 空 | 必填 |
| 主机 | 文本输入框 | localhost | |
| 端口 | 数字输入框 | 5432（PgSQL）/ 3306（MySQL） | |
| 初始数据库 | 文本输入框 | postgres | PgSQL 显示，MySQL 显示"数据库" |
| 用户名 | 文本输入框 | postgres | |
| 密码 | 密码输入框 | 空 | 含显示/隐藏切换按钮 |
| 保存密码 | 复选框 | 勾选 | |

**Tab：高级** [基于推断]
| 字段 | 类型 | 说明 |
|------|------|------|
| 连接超时 | 数字输入框（秒） | |
| 读取超时 | 数字输入框（秒） | |
| 编码 | 下拉框 | 字符集，如 UTF-8 |
| 保持连接间隔 | 数字输入框（秒） | |
| 使用压缩（MySQL 专有） | 复选框 | |

**Tab：数据库** [基于推断]
- 多选框列表：列出当前连接下所有数据库（或若未连接则提示"先测试连接"）
- 勾选的数据库将在连接树中展示

**Tab：SSL**
- `使用 SSL` 复选框（不勾选时下方内容置灰）
- SSL 模式：下拉框（require / verify-ca / verify-full / disable）
- `使用验证` 复选框（勾选后以下字段可用）
  - 客户端密钥：文本输入 + `...` 文件选择按钮
  - 客户端证书：文本输入 + `...` 文件选择按钮
  - 根证书：文本输入 + `...` 文件选择按钮
  - 证书撤销列表：文本输入 + `...` 文件选择按钮

**Tab：SSH**
- `使用 SSH 隧道` 复选框（不勾选时下方内容置灰）
- 主机：文本输入框
- 端口：数字（默认 22）
- 用户名：文本输入框
- 验证方法：下拉框（密码 / 公钥 / ssh-agent）
- 密码：密码输入框（验证方法=密码时显示）
- 私钥文件：文本 + `...` 文件选择按钮（验证方法=公钥时显示）
- 密钥口令：密码输入框（验证方法=公钥时显示）
- 保存密码：复选框

**Tab：HTTP** [基于推断]
- `使用 HTTP 隧道` 复选框
- Tunnel URL：文本输入框
- 用户名/密码：文本输入框

**Tab：备注**
- 多行文本域，填写备注信息

**弹窗底部按钮栏（左右分布）：**
- 左侧：`测试连接` 按钮（点击测试连通性，显示成功/失败提示）
- 右侧：`取消` / `保存` 按钮

## 5. 对象浏览器（"对象" Tab）

### 5.1 整体结构
"对象" Tab 是主内容区的固定首个 Tab，展示当前在连接树中选中节点的子对象列表。

**Content Toolbar（对象列表上方）：**

```
[新建] [编辑] [删除] [刷新]  |  [复制] [粘贴]  |  [切换视图：列表/网格]  |  [搜索输入框]
```

各按钮的启用状态随当前选中对象类型变化（例如：选中 Schema 时"新建"是创建新表，选中表时"编辑"变为"设计表"）。

### 5.2 对象列表视图

**列模式（默认）：**
选中 Schema 层级（PostgreSQL），列出该 Schema 下的表（或视图、函数等分类）：

| 列名 | 说明 |
|------|------|
| [图标] 名称 | 对象类型图标（表/视图/函数等）+ 对象名称 |
| OID | PostgreSQL 对象标识（PgSQL 专有） |
| 所有者 | 对象所属用户 |
| ACL | 权限信息 |
| 表类型 | 常规 / 外部 / 分区 |
| 分区属于 | 分区表的父表（若为分区） |
| 行 | 近似行数（来自统计信息） |
| 主键 | 主键数量 |

- 列表支持点击列头排序。
- 行选中：高亮显示，单次点击选中，双击打开（同右键→打开表）。
- 多选：`Shift+点击` 连续多选，`Ctrl/Cmd+点击` 单独多选。
- 搜索框实时过滤列表中的对象名称（模糊匹配）。
- 列表支持列宽拖拽调整。

**MySQL 下的对象列表（不显示 OID 等 PgSQL 专有列）：**

|------|------|

| 引擎 | InnoDB / MyISAM 等 |
| 行 | 近似行数 |
| 数据大小 | |

## 6. 右侧信息面板（Info Panel）

### 6.1 面板结构
右侧固定宽度 `200px` 的信息面板，显示当前选中对象的元数据。

**选中连接时：**
- 大图标（数据库类型图标）+ 连接名
- 类型标签（如 `PostgreSQL`）
- 共享按钮（暂不实现）
- 版本号
- 字符集

**选中数据库时：**
- 数据库名
- `数据库` 标签
- 连接名
- 字符集
- 排序规则

**选中 Schema 时：**
- Schema 名（大号文字）
- `模式` 标签
- 所属数据库名 + 连接名
- OID（PgSQL）
- 所有者
- 注释

**选中表时：**
- 表名（大号文字，右侧类型图标）
- `表` 标签
- 所属数据库 + Schema
- 行数
- 数据大小
- 索引大小
- 引擎（MySQL）/ 可选字段
- `有索引`：是/否
- `有触发器`：是/否
- `根页面数`（PgSQL 专有）

### 6.2 折叠行为
- 工具栏右侧有"查看"图标按钮，点击切换 Info Panel 显示/隐藏。
- 折叠后主内容区宽度自动扩展。

## 7. 表数据视图

双击连接树中的表节点，或双击对象列表中的表行，或右键→打开表，在新 Tab 中打开数据视图。

### 7.1 Tab 标题
格式：`[数据库图标] [表名]@[Schema]([连接名])`  
示例：`sessions@main (agent)`

### 7.2 数据视图 Content Toolbar

```
[保存] [撤销]  |  [导出] [导入]  |  [筛选面板切换]  |  [列管理]  |  [刷新]  |  [停止查询]
```

各按钮说明：
- **保存**：提交所有未保存的行内编辑（CRUD）。
- **撤销**：撤销当前未保存的编辑。
- **导出**：调出导出向导。
- **导入**：调出导入向导。
- **筛选面板切换**：展开/折叠上方筛选与排序面板。
- **列管理**：勾选显示/隐藏列，调整列顺序。
- **刷新**：重新拉取数据。
- **停止查询**：中断正在执行的查询。

### 7.3 数据网格

**列头：**
- 第一列固定为行号（只读，不可编辑）。
- 其余列为表字段，列头显示：字段名 + 类型图标（`#` 代表数字，`ᴬᴮᶜ` 代表文本，`⌛` 代表时间戳等）+ 排序方向图标。
- 点击列头：切换升序/降序排序（叠加排序：已选列不变，新选列追加）。
- 双击列头：重命名列（仅限视图，不修改表结构）。
- 拖拽列头：调整列顺序（仅视图层面）。
- 右键列头：隐藏列、冻结列、列属性。

**数据行：**
- 单击行选中（高亮背景）。
- 双击单元格：进入编辑态（行内文本输入框或对应编辑器）。
- `NULL` 值：显示为 `(NULL)` 灰色斜体，区别于空字符串。
- 长文本溢出：单元格省略显示，鼠标悬浮 Tooltip 显示全文。
- 布尔类型：显示为复选框图标（✓/✗）。
- JSON/数组类型：单行折叠显示 `{...}`，双击展开浮层完整编辑。

**行内编辑模式：**
- 双击进入编辑，当前行单元格变为可编辑 Input。
- 编辑后该行左侧显示铅笔图标（编辑标记）。
- Tab 键：跳到下一个可编辑单元格。
- Enter：提交当前单元格，跳到下一行同列。
- Esc：取消当前单元格编辑。
- 点击保存按钮或 `Ctrl+S`：提交所有已编辑行的变更（生成 UPDATE SQL 后台执行）。

**多行选中（行头点击）：**
- 点击最左侧行号列：选中整行。
- Shift + 点击行号：连续选中多行。
- 选中多行后，支持批量删除。

### 7.4 底部状态栏（数据视图页脚）

```
[+] [-] [✓] [✗] [↺] [⏹]    SELECT * FROM "public"."biz_issue" LIMIT 1000 OFFSET 0    |◀ ◀ [1] ▶ ▶| ⚙    209 条记录在第1页  上次刷新时间: 刚刚
```

**左侧操作按钮：**
- `+`（添加行）：在末尾插入新空行，进入编辑态。
- `-`（删除行）：删除选中行（弹确认提示）。
- `✓`（确认）：提交当前编辑。
- `✗`（取消）：取消当前编辑。
- `↺`（刷新）：重新拉取数据。
- `⏹`（停止）：终止正在查询中的请求。

**中间：** 当前执行的 SQL 语句（只读展示）。

**右侧翻页控件：**
- `|◀` 首页，`◀` 上一页，当前页码输入框，`▶` 下一页，`▶|` 末页。
- `⚙` 设置每页记录数（100 / 500 / 1000 / 5000 可选）。
- 总记录数文字：`X 条记录在第 Y 页`。
- 上次刷新时间：`上次刷新时间: X 秒前` / `刚刚`。

### 7.5 筛选与排序面板

点击 Content Toolbar 中的筛选按钮，在数据网格上方展开筛选面板。

```
┌─────────────────────────────────────────────────────────────────┐
│  筛选  ↑ ↓                                                       │
│  ☑ [字段下拉] [条件下拉] [值输入]  and ▼  [+] [Q+]              │
│  ☑ [字段下拉] [条件下拉] [值输入]         [+] [Q+]              │
│                                                                  │
│  排序方式  [+]  点击 '+' 以添加排序准则                           │
│  [字段下拉] [ASC▼]  [×删除]                                      │
│                                                                  │
│  [应用筛选 & 排序]  已编辑准则                                    │
└─────────────────────────────────────────────────────────────────┘
```

**筛选条件行：**
- 复选框：启用/禁用该条件。
- 字段下拉：表字段列表。
- 条件下拉：`包含` / `等于` / `不等于` / `大于` / `小于` / `不是 null` / `是 null` / `以...开头` / `以...结尾` / `在列表中`。
- 值输入框：条件值，`不是 null` / `是 null` 时隐藏。
- 逻辑连接：下拉 `and` / `or`（在条件行末尾）。
- `[+]` 添加常规条件行。
- `[Q+]` 添加参数化条件（可作为查询参数传入）。
- `↑↓` 调整条件行顺序。

**排序规则行：**
- 字段下拉 + `ASC`/`DESC` 下拉 + `×` 删除按钮。
- `[+]` 添加排序字段。

**底部按钮：**
- `应用筛选 & 排序`（蓝色主 CTA 按钮）：执行筛选并刷新数据。
- `已编辑准则`（灰色文字标签）：提示当前有未应用的改动。

## 14. 数据模型与接口约定

### 14.1 前端核心数据结构

```typescript
interface DbConnection {
  id: string
  name: string
  type: 'postgresql' | 'mysql' | 'sqlite'
  group?: string
  host?: string
  port?: number
  database?: string
  username?: string
  // 密码不存在前端，通过 credentialRef 引用后端 keyring
  credentialRef?: string
  ssl?: SslConfig
  ssh?: SshTunnelConfig
  http?: HttpTunnelConfig
  connectedAt?: string
  status: 'connected' | 'disconnected' | 'error'
}

interface SslConfig {
  enabled: boolean
  mode: 'require' | 'verify-ca' | 'verify-full' | 'disable'
  useVerify: boolean
  clientKeyPath?: string
  clientCertPath?: string
  rootCertPath?: string
  crlPath?: string
}

interface SshTunnelConfig {
  enabled: boolean
  host: string
  port: number
  username: string
  authMethod: 'password' | 'publickey' | 'agent'
  credentialRef?: string
  identityFilePath?: string
}

interface DbObject {
  name: string
  type: 'table' | 'view' | 'materialized_view' | 'function' | 'sequence'
  schema?: string
  oid?: number           // PostgreSQL 专有
  owner?: string
  rowCount?: number
  dataSize?: number
  indexSize?: number
  hasIndexes: boolean
  hasTriggers: boolean
  comment?: string
}

interface TableField {
  name: string
  type: string
  length?: number
  precision?: number
  notNull: boolean
  isPrimaryKey: boolean
  isForeignKey: boolean
  default?: string
  collation?: string
  comment?: string
}
```
