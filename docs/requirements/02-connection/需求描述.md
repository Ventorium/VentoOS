# 2期功能，连接与端口

## 功能
1. 增加 SSH 服务器管理
2. 增加 WebShell，不仅本地支持，SSH服务器也支持
3. 端口映射，支持将ssh服务器上的端口映射到本地，统一管理
4. 服务暴露，可以很方便的将本地的/服务器的http服务暴露到公网，支持基础认证拦截
5. web页面增加用户登录，这一阶段也只做单用户，但是需要加密码验证，页面长期不访问或sessionStorage状态丢失则锁住页面，类似MacOS的锁屏页面，样式也要一样
