# feature
1. 添加系统级监控面板应用，有点类似windows的资源消耗查看器，可以查看服务所运行的机器的cpu/内存/磁盘使用情况。还需要展示当前ventoos所消耗的cpu/内存/存储占用情况
2. 另外在ssh服务器管理里也增加服务器资源占用预览，也是查看服务器的cpu/内存/磁盘使用情况
3. 在UI层和native层提供统一的 抽象的、可复用的、跨平台的资源检查的能力，让监控面板和ssh管理这2个应用能复用能力
4. 要用图表展示，所以前端需要先做组件抽象，组件库要尽量简单，不要用echarts这样的大户

# 验收标准
1. 有按照统一注册应用的方式新注册一个应用“监控面板”
2. 监控面板应用可以在监控面板中看到当前系统的cpu负载（包括每个核心的负载）和历史曲线图，内存占用/总内存和历史曲线图，磁盘的总量和剩余情况（如果有多盘就统计每个盘的情况）
3. 监控面板应用可以查看当前VentoOS系统所占用的CPU、内存以及历史消耗的曲线图。还可以通过 performance.measureUserAgentSpecificMemory + Compute Pressure API 等方式显示网页端大致消耗了多少cpu和内存
4. 监控面板应用cpu/内存默认5秒刷新一下，磁盘默认1分钟刷新一下
5. 监控面板应用需要注册“偏好设置”菜单，点击后用通用的设置面板显示能力（如果没有就抽象一个，和explorer的偏好设置能力保持统一）显示配置，配置项包括刷新频率设置（包括机器的、VentoOS的、网页的刷新频率）、是否在Tray中显示（默认不显示，开启后也可以设置刷新频率）。现在前端好像还没有注册tray的能力，因此需要先设计一个注册Tray的能力（Tray里也要有数字显示，所以能力设计得尽量完整和丰富些），这个tray没有子菜单，点击就是打开监控面板应用即可
6. 监控面板应用要兼容windows/mac/linux机器
7. “ssh管理”应用选中某个已添加的服务器，在点击连接后在shell右侧显示一个资源消耗面板，这个面板可关闭，关闭后可以再手动点开。默认会自动展开显示
8. “ssh管理”应用注册“偏好设置”菜单，点击后用通用的设置面板显示能力显示配置，目前只需要提供一个“是否在连接后自动打开资源监控”的选项，默认勾选
