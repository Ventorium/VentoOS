## 实现详情

### 1. 直接修复点

- `web/src/apps/ssh/ResourceMonitorPanel.tsx`：侧边分割线、顶部下边线改为 `var(--vos-border-subtle)`，背景统一为 `var(--vos-bg-surface)`。

### 2. 共享组件回补

- `web/src/components/charts/GaugeChart.tsx`
- `web/src/components/charts/BarChart.tsx`
- `web/src/components/charts/LineChart.tsx`

以上三个共享图表组件的默认边线 / 轨道 / 网格颜色从无效旧 token 改为 `var(--vos-border-subtle)`，避免监控页继续从共享组件拿到错误的白色分隔效果。
