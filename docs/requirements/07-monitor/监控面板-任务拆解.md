# 监控面板 — 任务拆解

## 原始需求概述

1. 系统级监控面板应用：查看本机 CPU/内存/磁盘，及 VentoOS 自身资源消耗
2. SSH 管理中集成服务器资源占用预览
3. UI 层和 Native 层提供统一、可复用、跨平台的资源检查能力
4. 轻量图表组件库（不用 echarts 等大库）
