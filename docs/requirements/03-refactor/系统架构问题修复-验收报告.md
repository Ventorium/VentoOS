## 总结

9 项系统架构问题已全部修复：
1. **菜单系统**：新建 AppMenu/Tray 注册机制，TopBar 自动渲染当前焦点应用菜单和 Tray 图标
2. **Explorer**：迁移到注册系统，删除自定义菜单代码
3. **文件路径**：修复 VfsFilePickerModal 中 `local_path` → `root` 字段引用 bug
4. **K8s**：工具栏 namespace 改为下拉选择器
5. **AI 设置**：系统设置新增"AI 助手"分类入口
6. **Terminal**：新建独立终端应用（多标签 + 字号 + 重命名）
7. **SSH Shell**：使用 russh 实现真实 SSH 连接（密码/密钥认证 + PTY + shell relay）
8. **DB 文件选择**：SQLite 路径使用 PathPickerInput 组件
9. **DB 连接测试**：新增 inline test 端点，表单内可测试连接
10. **DB 序列化**：修复 enum rename bug + sqlite_path 字段对齐
