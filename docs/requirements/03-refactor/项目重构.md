# 系统分层重构

## 原因

为了构建更好的、更完备的WebOS系统，现在的架构需要重新设计，主要解决分层问题

## 架构分层

1. 系统内核层

1.1 文件系统

基于VFS的文件系统层

1.2 进程管理

每一个打开的应用（K8s 终端、Redis 客户端）都是一个虚拟进程，拥有独立的上下文和 PID

1.3 窗体管理

负责窗口的层级（z-index）、拖拽投影、缩放动画及状态持久化

1.4 事件通知

1.5 应用管理

2. 通信层

2.1 内核通信

2.2 页面通信

2.3 事件总线

3. 服务层

3.1 文件操作

3.2 认证管理

3.3 审计日志

4. 应用层

4.1 应用下载与安装与卸载

4.2 应用启动与关闭

4.3 应用生命周期

4.4 应用配置管理与存储

4.5 应用接口注册

4.6 应用隔离

5. 表现层

5.1 UI组件

5.2 UI桌面

- Dock
- MenuBar
- Tray
- Notification
- Settings
- AI Chat
- Window Manager

5.3 用户应用
