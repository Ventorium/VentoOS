## 实现详情

### 1. AppMenu/Tray 注册系统

**新建文件：**
- `web/src/kernel/apps/menu.ts` — 类型定义（AppMenuItem, AppMenuEntry, AppMenuGroup, AppTrayConfig）
- `web/src/kernel/apps/menu-store.ts` — Zustand store（registerAppMenus, registerAppTray 等）
- `web/src/kernel/apps/menu-hooks.ts` — React hooks（useActiveAppMenus, useAllTrays 等）

**修改文件：**
- `web/src/kernel/index.ts` — 导出新 API
- `web/src/shell/TopBar/index.tsx` — 左侧渲染应用菜单组，右侧渲染 Tray 图标

### 2. Explorer 菜单迁移

**修改文件：** `web/src/apps/explorer/index.tsx`
- 新增 useEffect 注册菜单（设置、新建窗口、隐藏窗口、退出）
- 删除 showSettingsMenu 状态
- 删除 ~80 行自定义定位菜单 UI 代码
- 删除路径栏中的 "Explorer" 按钮

### 3.1 FilePicker 路径补全修复

**修改文件：** `web/src/shell/FilePicker/index.tsx`
- `handleConfirm` 中将 `(selectedMount as unknown as { local_path?: string }).local_path` 改为 `selectedMount.root`
- 正确拼接 mount root + relative path，处理尾部斜杠

### 3.2 K8s Namespace 切换

**修改文件：** `web/src/apps/kubernetes/index.tsx`
- 工具栏中的静态 namespace 文本替换为 `<select>` 下拉选择器
- onChange 调用 pickNs 切换 namespace 并刷新资源

### 4. AI 设置入口

**修改文件：** `web/src/apps/settings/index.tsx`
- 新增 'ai' 分类（Bot 图标）
- AIPanel 组件：说明文字 + "打开 AI 控制中心" 按钮
- 按钮调用 openWindow('ai-assistant') 打开 AI 应用

### 5. Terminal 应用

**新建文件：**
- `web/src/apps/terminal/manifest.ts` — 应用注册（id: 'terminal', multiWindow: true）
- `web/src/apps/terminal/index.tsx` — 多标签终端（lazy-load WebShell, tab 管理, 字号调节, 双击重命名）

**修改文件：** `web/src/apps/index.ts` — 注册 terminalManifest

### 6. SSH Shell 真实连接

**修改文件：** `native/crates/ventoos-server/src/shell.rs`
- 实现 `handle_ssh_shell()` 使用 russh：
  1. 通过 SshInfoProvider::resolve 获取连接信息和凭据
  2. russh::client::connect 建立 SSH 连接
  3. 支持密码认证和密钥认证
  4. request_pty + request_shell 打开远程终端
  5. channel.into_stream() 获取异步读写流
  6. tokio::select! 双向 relay：WebSocket ↔ SSH channel

### 7. DB SQLite 文件选择器

**修改文件：** `web/src/apps/database/index.tsx`
- 导入 PathPickerInput 组件
- 替换 SQLite 路径的 `<input>` 为 `<PathPickerInput mode="file">`

### 8. DB 创建时测试连接

**后端修改：**
- `native/crates/ventoos-db/src/routes.rs` — 新增 POST /api/db/connections/test 路由和 handler
- `native/crates/ventoos-db/src/manager.rs` — 重构：提取 `test_config()` 私有方法，新增 `test_connection_inline()` 公开方法

**前端修改：**
- `web/src/infra/api/client.ts` — 新增 testDbConnectionInline API
- `web/src/apps/database/index.tsx` — 新增"测试连接"按钮 + 结果显示（成功/失败 + 延迟 + 版本信息）

### 9. DB 序列化 bug 修复

**修改文件：**
- `native/crates/ventoos-db/src/types.rs`:
  - DbEngine 枚举：替换 `#[serde(rename_all = "snake_case")]` 为单独的 `#[serde(rename = "postgresql")]` / `"mysql"` / `"sqlite"`
  - `file_path` → `sqlite_path`（带 `#[serde(alias = "file_path")]` 向后兼容）
- `native/crates/ventoos-db/src/manager.rs` — 所有 `file_path` 引用改为 `sqlite_path`
