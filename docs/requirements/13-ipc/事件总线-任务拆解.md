# IPC EventBus — 任务拆解

## 原始需求

设计系统级内部通信机制，实现应用间事件注册、发送、接收。核心场景：K8s 应用点击 PostgreSQL 服务时通过事件触发 Database 应用自动打开并添加连接。

## 需求拆解

| 序号 | 原始需求 | 子任务 | 验收标准 | 状态 |
|------|----------|--------|----------|------|
| 1 | 系统提供注册接口 | T1: 定义事件类型系统 | TypeScript 类型完整定义，编译通过 | 已完成 |
| 2 | 系统提供注册接口 | T2: 实现 EventBus 核心类 | on/emit/getHandlers/unregisterApp 方法可用 | 已完成 |
| 3 | 应用注册事件处理 | T3: 扩展 AppManifest 支持 emits/handles 声明 | manifest 编译通过，类型正确 | 已完成 |
| 4 | 应用发送事件 | T4: 实现权限校验（emit 前检查 manifest） | 未声明事件发送被拒绝 | 已完成 |
| 5 | K8s 发送 open:postgres | T5: K8s 应用集成 EventBus，添加"打开数据库"菜单 | 右键菜单出现"打开数据库"项 | 已完成 |
| 6 | Database 接收事件 | T6: Database 应用注册事件处理器 | 收到事件后自动添加/更新连接 | 已完成 |
| 7 | 自动打开应用 | T7: EventBus 集成 WindowManager 实现 autoOpen | 未打开应用时自动打开窗口 | 已完成 |
| 8 | 事件携带参数 | T8: 实现结构化载荷与 connectionId 逻辑 | connectionId 存在为编辑，不存在为新增 | 已完成 |
| 9 | 调试支持 | T9: 事件日志环形缓冲区与脱敏 | 日志可查，密码脱敏 | 已完成 |
| 10 | React Hooks | T10: 实现 useEventHandler / useEventEmitter | Hook 正确注册/注销，组件卸载自动清理 | 已完成 |
| 11 | 测试 | T11: EventBus 核心单元测试 | 所有测试通过 | 已完成 |
| 12 | 测试 | T12: Hook 单元测试 | 所有测试通过 | 已完成 |
| 13 | 构建验证 | T13: 前端构建与 lint | `pnpm build` + `pnpm test` 通过 | 已完成 |
| 14 | Redis 集成 | T14: Redis 应用注册 open:redis 事件处理器 | 收到事件后自动添加/连接 Redis | 已完成 |
