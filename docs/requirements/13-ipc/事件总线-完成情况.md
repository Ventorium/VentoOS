## 架构设计要点

1. **分层归属**: EventBus 位于 Kernel 层 (`web/src/kernel/ipc/`)，是 System Capability 的一部分
2. **Manifest 驱动**: 应用必须在 manifest 中声明 emits/handles，EventBus 运行时校验
3. **权限校验**: emit 校验 senderManifest.emits，on 校验 handles
4. **自动打开**: emit 时检查目标应用是否有窗口，无则 openWindow，有则 focusWindow
5. **循环依赖规避**: 动态 import window/manager 和 window/store
6. **安全**: 日志自动脱敏 password/secret/token/credential/privateKey
7. **去重**: 通过 eventId Set 防止重复处理，超过 1000 条自动裁剪
8. **可扩展**: AppEventMap 支持 module augmentation 扩展自定义事件
