# 超级终端 — 任务拆解

## 原始需求概述

将现有 SSH 管理和终端两个独立应用合并为统一的"超级终端"应用，包含以下功能模块：

1. **本地终端** — 支持分屏（水平/垂直切分）、右键菜单（复制/粘贴/清屏/切分等）
2. **SSH 服务器管理** — 分组管理、增删改查、批量操作、导入 SSH 配置、跳板机/代理支持
3. **SSH 会话** — 文件树 + Monaco 编辑器 + 多标签终端 + 服务器监控面板
4. **端口映射** — SSH 端口转发管理，支持增删改查、开机自启、批量操作
5. **外网访问** — 通过 Pinggy/localhost.run/Serveo 等服务暴露本地服务
6. **左侧面板** — 常用命令管理 + 终端全局设置（Shell 程序、字体、光标等）
7. **顶部 Chrome 式标签** — 管理所有 SSH 会话标签，支持溢出折叠
