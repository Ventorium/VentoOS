# 文件打开系统 — 完成情况

## 原始需求与拆解表

| 序号 | 原始需求(AC) | 子任务 | 验收标准 | 状态 |
|------|-------------|--------|---------|------|
| 1 | 默认预览和打开方式改为注册制 | 内核 manifest 新增 `fileOpenAssociations`/`filePreviewAssociations`；新增 `getAllAppsForFile`/`getOpenAppsForFile`/`getPreviewAppsForFile` | AppManifest 支持三种关联方式；旧 `fileAssociations` 向后兼容 | 已完成 |
| 2 | 图片编辑器应用 | 新建 `image-editor` 应用（Canvas 画布编辑器） | 旋转/缩放/裁剪/画笔/橡皮擦/导出 PNG/JPG/WEBP + 压缩质量 | 已完成 |
| 3 | 右键选择打开方式 | Explorer 右键菜单增加"打开方式"子菜单 | 显示所有注册应用（含类型标签），可选择任意应用打开文件 | 已完成 |
| 4 | 设置默认打开方式 | 增加"设置默认打开方式"弹框 + `file-defaults` 持久化 store | 应用列表 + "同时打开该文件" 复选框 + 持久化到 system storage | 已完成 |
| 5 | Office 编辑器应用 | 新建 `office-editor` 应用（DOCX/XLSX/CSV 查看） | DOCX 渲染(docx-preview)；XLSX 解析(自定义解析器)；CSV 表格；隐藏于 Dock | 已完成 |
| 6 | 压缩文件编辑器 | 新建 `archive-editor` 应用 + Explorer "压缩" 菜单 + Rust 后端增强 | 浏览/解压/压缩；密码支持(AES-256)；zip/tar.gz/7z 格式；压缩弹框(格式+加密) | 已完成 |
| 7 | 字体预览器 | 新建 `font-preview` 应用 | FontFace API 动态加载；多尺寸预览；字符网格；自定义文本；同时注册打开+预览 | 已完成(预览部分；安装功能待后端 font API) |
| 8 | 文件图标系统 | 新建 `file-icons.ts` 模块 + Explorer 集成 | 覆盖图片/视频/音频/文档/表格/演示/代码/配置/脚本/标记/数据库/压缩包/字体/可执行文件等 | 已完成 |
| 9 | 无后缀名文件不提供设置默认打开方式 | Explorer 右键菜单条件判断 | 无后缀名文件只显示"打开方式"子菜单，不显示"设置默认打开方式" | 已完成 |
| 10 | Dock 图标动态管理 | 新建 `dockPinsStore.ts` + Dock 组件改造 | 右键"从 Dock 中移除"/"保留在 Dock 中"；终端不可移除；显示 pinned + running | 已完成 |
