# 文件打开系统 — 任务拆解

## 架构设计

### 注册系统重构

**现状**：`AppManifest.fileAssociations` 单一字段，`getAppsForFile(ext)` 返回所有关联应用。

**目标**：分离 "打开/编辑" 和 "预览" 两种注册能力。

```
AppManifest {
  fileOpenAssociations?: string[]    // 打开/编辑能力 (如图片编辑器)
  filePreviewAssociations?: string[] // 预览能力 (如文件查看器)
  fileAssociations?: string[]        // 向后兼容，等同于 fileOpenAssociations
}
```

**关键函数**：
- `getOpenAppsForFile(ext)` — 返回注册了打开能力的应用
- `getPreviewAppsForFile(ext)` — 返回注册了预览能力的应用
- `getAllAppsForFile(ext)` — 返回所有关联应用（打开 + 预览）

### 默认打开方式

- 存储在系统级 AppStorage: `system:file-defaults` → `{ "png": "image-editor", ... }`
- 双击流程：
  1. 获取扩展名
  2. 查找默认应用 → 如有，直接打开
  3. 否则查找预览应用 → 如有，打开第一个（file-viewer）
  4. 否则 file-viewer 以二进制查看
- 无后缀名文件：不可设置默认，始终以 file-viewer 二进制查看

### Dock 管理

- 新增 `pinnedApps: string[]` 到 dock 存储
- Dock 显示：已固定应用 + 运行中但未固定的应用
- 右键：固定/取消固定，terminal 不可移除

### 文件图标

- 创建扩展名 → 图标/颜色映射表
- 覆盖常见文件类型：文档、表格、PPT、图片、视频、音频、代码、压缩包、字体等

### 新应用

| 应用 | 注册类型 | 隐藏 | 说明 |
|---|---|---|---|
| Image Editor | open: 图片类 | 否 | 旋转/缩放/裁剪/画笔/橡皮擦/导出 |
| Office Editor | open: office类 | 是 | 基于 document repo 的 OnlyOffice 集成 |
| Archive Editor | open: 压缩类 | 否 | 浏览/解压/压缩，支持密码 |
| Font Previewer | open+preview: 字体类 | 是 | 字体预览/安装，Rust 后端检测 |
