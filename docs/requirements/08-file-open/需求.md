# feature
1. 为了在web端能够尽量完整的体验文件管理器的能力，需要提供系统级的文件预览和打开程序的注册能力，从而实现对于任意后缀名的文件的预览和打开能力。因此需要对现有的应用打开能力进行重构
2. 可针对每个后缀名的文件右键选择打开方式，也可以设置后续都使用该文件来打开
3. 阅读 [.repos/document](https://github.com/ranuts/document) 仓库里的能力，按照它这个项目里的实现方式给VentoOS添加office文档查看/编辑office文件能力，添加zip文件预览能力，可解压/压缩zip文件，字体文件可预览字体效果
4. 不同的后缀名显示不同的文件图标

# 验收标准
1. 将现有的默认预览和打开方式改成注册，这样还保持原有的文件预览和打开方式的能力
2. 创建一个图片编辑器应用，该应用可以打开/编辑图片，同时也注册了图片打开能力，不注册预览能力。该应用可以对图片进行旋转、缩放、裁剪、彩笔绘画、橡皮擦等常见图片处理能力，可导出png/jpg/webp，可选择图片压缩质量
3. 右键explorer中任意一个存储源（包括s3/smb/sftp/webdav等所有的存储源）中的图片，选择打开方式，可以选择默认的FileViewer应用或者图片编辑器应用，选择任意一个就会用该应用来打开该图片。
4. 右键explorer中任意一个存储源中的图片，选择打开方式，选择“设置默认打开方式”，会出现所有应用的弹框，选择某个应用后，底部有个“同时打开该文件”，点击确定，后续同样的后缀名的文件就会用刚选择的应用来打开了。同时根据刚是否勾选了“同时打开该文件”来决定是否用该应用来打开该文件
5. 创建Office编辑器应用，不停留在dock中，注册ppt/pptx/doc/docx/xls/xlsx文件的打开方式，这些文件都可以通过该应用来打开，不注册预览。office文件的保存在项目的issue里有讨论，可以做到纯前端存储。
6. 添加压缩文件编辑器应用。注册zip/7z/rar等常见后缀名的打开方式，不注册预览能力。带密码的压缩文件在解压时有个密码输入框。在选择文件（支持多文件/目录）后右键增加“压缩”菜单，点击后出现压缩选项弹框，可选择是否加密，如果加密添加密码输入框和确认密码输入框（需要一致），以及压缩格式。压缩/解压的能力是比较复杂的，需要现在技术实现调研再实现，要支持尽量多的压缩类型。后端rust来实现,可以直接参考 https://github.com/tokimo-lab/tokimo-universal-archiver 项目的实现方式
7. 双击explorer中任意一个存储源中的字体文件，可以用字体预览器应用（同时注册打开方式和预览能力）来显示该字体效果（使用rust提供临时url+动态加载的方式），点击应用页面的安装按钮，可将字体安装到系统中。同时对于已安装的字体安装按钮要显示已安装，不可点击（需要rust后端检测字体是否已安装）
8. 常见的后缀名对应的图标要不同且体现意义，比如doc/docx文件要显示文档图标，尽量要好看，尽量支持尽可能多的文件类型
9. 无后缀名的文件不提供选择默认打开方式的能力，但是可惜选择打开方式，即不可以更改无后缀名的文件的默认打开方式，默认打开方式还是现在的字节码查看方式
10. dock应用图标可右键选择“从dock中移除“和”保留在dock中“从而实现动态管理dock图标，但是控制台不可修改
