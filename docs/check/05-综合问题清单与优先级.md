# VentoOS 综合问题清单与优先级

- 目标：把本轮多角色审查结果合并为可执行问题列表。
- 优先级定义：
  - P0：高概率形成敏感信息泄露或严重安全事故
  - P1：已影响核心功能真实性、平台边界或高风险操作
  - P2：会持续积累架构债或误导用户，但可短期带标识运行
  - P3：规范与环境问题，需纳入治理但不阻塞当前主线

## 三、备注

- “代理目标限制”本轮完成的是静态 host 防护，DNS 解析后的内网地址识别仍可继续增强。
- “WebSocket 问题”本轮已完成订阅管理与插件消息转发，后续重点转向跨插件语义扩展。

## 四、建议的修复顺序

1. 先处理安全泄露面：token in URL、代理边界、下载完整性校验。
2. 再处理假实现：SSH test、SQL save、TableDesigner save、K8s batch delete。
3. 随后补平台骨架：WebSocket 订阅管理、AppMessage 转发、真实指标采集。
4. 最后补回归闸门：API Client、Mount、File Provider、SSH 关键链路测试。

## 五、建议的负责人映射

- 平台后端：WebSocket 事件总线、SSH 真连通性、代理边界、下载校验
- 前端应用：SQL 保存、表设计器保存、K8s 批量删除、未完成态显式标识
- 安全治理：token/header 迁移、日志脱敏、WebDAV 设计收口
- 质量保障：关键模块集成测试、假实现验收闸门
